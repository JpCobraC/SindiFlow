SindiFlow

Apresentação – Aplicativo Móvel de Vistoria Predial

Sobre o SindiFlow

O SindiFlow é um aplicativo móvel nativo desenvolvido com Expo SDK 54 para gestão de vistorias prediais preventivas. Ele permite que técnicos de campo capturem fotos, registrem geolocalização e sincronizem dados offline com o backend em Supabase.


  • Offline-First: Todas as operações são salvas localmente via SQLite antes da sincronização
  • Rastreamento por Geolocalização: Coordenadas de GPS são obrigatórias para cada vistoria
  • Gestão de Fotos: Imagens comprimidas armazenadas via expo-file-system
  • Resolução de Conflitos: Estratégia "última escrita vence" (last-write-wins) com comparação de timestamp
  • Colaboração em Equipe: Acesso multiusuário com permissões baseadas em funções (RBAC)

Regras de Negócio (RF/VRF)

RF-VIST-001

Uma vistoria só pode iniciar com o status RASCUNHO.

RF-VIST-002

Só é possível finalizar se no mínimo 80% dos itens estiverem marcados.

RF-VIST-003

Itens com status CRÍTICO bloqueiam a finalização caso não haja justificativa.

RF-VIST-004

A geolocalização é obrigatória para que a vistoria seja considerada válida.
